Verify a run

Two checks: corner accuracy + decode rate on simulated captures, and a loopback that pushes a real frame sequence through the model until the bytes come back identical.

Run the evaluation

Level 0 = clean screen, 1.0 = harsh (blur, tilt, glare, vignetting). The number to beat: decode rate at 0.6.

Corner error is the mean distance between predicted and true grid corners, as a fraction of the frame side. Below ~0.05 the demodulator is comfortable; above ~0.15 it leans on the calibration ring to recover.

Loopback (S2C path)

Renders a transfer with the current settings, simulates a camera looking at it, decodes with the active model and compares payloads byte-for-byte.
